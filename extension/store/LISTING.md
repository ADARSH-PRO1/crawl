## Name
bizfy Scraper

## Summary (132 characters max; this is also the manifest description)
Scrape any list on the page you are looking at into a table. One click, no code, nothing leaves your browser.

## Category
Productivity (Chrome, Edge). Firefox: pick the closest category the form offers.

## Detailed description
bizfy Scraper turns the list on any web page into a table you can copy or download.

Click the icon and it finds the main list on the page: products, search results, rows of a table, cards, posts, jobs, directory entries. Not the list you wanted? Press Change list. Rename or hide columns, then copy the table to a spreadsheet, or download it as CSV or JSON.

More than one page of results? Choose how to load more: scroll down, click "load more", or follow the "next page" links, up to 20 pages and 2000 rows. Duplicate rows are removed for you.

Need details that are not in the list? "Scrape each URL" opens each linked page of the same site (up to 30, two at a time, politely paced) and adds its title, description, image and labelled values such as price or availability as new columns. "Page details" does the same for the page you are on.

Save what you set up as a template for a site, and it is applied the next time you open that site. Templates can be exported and imported.

Private by design:
- It works on the page you are looking at, in your own browser, so pages behind your own login work too.
- Nothing is sent anywhere. No account, no servers, no analytics, no ads.
- It asks for access to a site only when you choose next-page or scrape-each-URL, and only for that site.
- It never logs in for you, never fills forms and never tries to get past CAPTCHAs or bot checks. Respect each site's terms of use and robots rules.

## Single purpose (Chrome form)
Extract the repeated list of items on the page the user is viewing into a table the user can copy or download.

## Permission justifications (Chrome form)
- **activeTab**: read the page the user clicked the icon on, and nothing else.
- **scripting**: inject the extension's own reading script into that page.
- **storage**: keep the user's saved templates and last-used settings on their device.
- **Optional host access**: requested for one site at a time, only when the user chooses "Click next page" or "Scrape each URL", to open further pages of that same site. Never requested in advance and never used for another site.
- **Remote code**: none. **Data collection**: none (tick every "does not collect" box; certify that data is not sold, not used for unrelated purposes and not used for creditworthiness).

## Firefox specifics
- `data_collection_permissions` is `none` in the manifest: the add-on collects nothing. Minimum Firefox 140 (Android 142), because that release introduced that field.
- **Notes for the reviewer**: no minification and no bundler. `detect.js` is generated from `app/scrape_detect.js` by `python scripts/build_extension.py` (a text wrap, no transformation); every other file ships exactly as in `extension/src/`. To rebuild: Python 3.10+, run `python scripts/build_extension.py --target firefox`. If AMO asks for source code, upload the repository files `extension/`, `app/scrape_detect.js` and `scripts/build_extension.py`.
- Firefox for Android opens the window as a tab (there are no popup windows there): tick this in `MANUAL_TEST.md`.
